# Contributing

Thanks for helping. MacEmojis is a small SwiftUI/AppKit app; keep changes focused.

## Build

```bash
brew install xcodegen
make run
make test
```

The project is generated by XcodeGen from `project.yml`; do not edit `MacEmojis.xcodeproj` by hand.

Current builds are Apple Silicon only because the Emo SDK does not compile for x86_64 on macOS. The project uses ad-hoc signing by default so it builds without a certificate. Accessibility grants are tied to the signing identity, so a rebuild with a different signature may need a fresh grant.

For a stable grant, create `Config/Local.xcconfig` (gitignored):

```xcconfig
DEVELOPMENT_TEAM = YOUR_TEAM_ID
CODE_SIGN_IDENTITY = Apple Development
```

`Config/Signing.xcconfig` includes it automatically.

## Pull requests

- Run `make test`.
- Add a test for non-trivial logic (sentence slicing, placement, insertion).
- Keep the privacy promise: no telemetry, no new network calls, no text logging.
- Describe the app and macOS version you tested with.
- Keep the diff small; separate refactors from behavior changes.

## Code style

Follow the surrounding Swift style. Prefer small types and explicit names. Comments explain *why*, not *what*.

## Reporting bugs

Use the issue templates. Include your macOS version, the app version, the app you were typing in, and steps to reproduce. Do not paste real private text; redact it.
