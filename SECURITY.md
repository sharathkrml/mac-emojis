# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's **Report a vulnerability** button under the repository's [Security tab](https://github.com/sharathkrml/mac-emojis/security/advisories/new). Do not open a public issue.

Include:

- macOS version and MacEmojis version
- The app you were typing in, if relevant
- Steps to reproduce
- What you expected and what happened

You can expect an acknowledgement within a few days. Please give me a reasonable window to fix the issue before disclosing it publicly.

## Scope

MacEmojis runs locally and reads text through macOS Accessibility. Issues involving text exposure, unintended network requests, clipboard handling, or signing and updates are in scope.

Please do not include real passwords, private messages, or other sensitive text in a report. Redact it first.
